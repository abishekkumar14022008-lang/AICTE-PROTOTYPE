# AICTE Complaint Monitoring System

## About the Project
This is a simple web app prototype for viewing and tracking institution-related complaints.

It is made for a hackathon project. The complaint details shown in the app are fictional sample data, not real AICTE records.

## Main Features
- View total, pending, resolved, and overdue complaints.
- Add new complaints and edit or delete existing ones.
- Search and filter complaints by status, category, department, and priority.
- Change a complaint's status and view its status history.
- View charts and reports about complaints.
- Get in-app alerts for overdue, near-deadline, and critical complaints.
- Save changes in the same browser.
- Export complaint data as a JSON file.
- Use the app on desktop and mobile screens.

## Tools Used
- HTML
- CSS
- JavaScript
- Chart.js for charts

## How to Run
1. Download the HTML file.
2. Open the file in a web browser such as Chrome or Edge.
3. The dashboard will open.
4. An internet connection is needed to load the charts from Chart.js.

No installation is required.

## Important Notes
- This is only a demo prototype. It is not connected to the official AICTE system.
- The sample complaints are fictional.
- Changes are saved only in the browser you use. They are not shared with other users or devices.
- The alerts appear inside the website. The app does not send real emails or SMS messages.
- Use **Reset Demo Data** to restore the original sample complaints. Your changes will be lost.
- Use **Export JSON** to download the current complaint data.

## Future Improvements
- Add a backend and database.
- Add secure login for different users.
- Allow multiple users to see updates in real time.
- Send email or SMS alerts.
- Connect to official systems only with proper authorization.

## Project Goal
The goal is to make complaint tracking easier by showing complaint details, status, deadlines, department workload, and reports in one dashboard.
